# 🎓 Eduprajna Learning Management System (LMS)

A modern **Learning Management System (LMS)** built using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)** for **Eduprajna**, a technology training company based in Bengaluru, India.

This LMS is designed to manage **courses, students, trainers, batches, assignments, quizzes, attendance, and certificates** — providing a seamless digital learning experience for both online and offline training programs.

---

## 🚀 Features

### 👩‍🎓 Student Portal
- Browse available courses and enroll easily  
- Access recorded and live sessions  
- Take quizzes and submit assignments  
- Track course progress and attendance  
- Download completion certificates  

### 🧑‍🏫 Trainer Dashboard
- Create and manage courses and lessons  
- Upload videos, notes, and assignments  
- Track student progress and attendance  
- Grade assignments and view analytics  

### 🛠️ Admin Panel
- Manage courses, students, and trainers  
- Create batches, schedules, and reports  
- Monitor payments, attendance, and certificates  
- Send announcements and notifications

## 🧩 Tech Stack

| Layer | Technology |
|--------|-------------|
| **Frontend** | React.js (with TailwindCSS / Material UI) |
| **Backend** | Node.js + Express.js |
| **Database** | MongoDB (Mongoose ORM) |
| **Authentication** | JWT (JSON Web Token) |
| **Storage** | AWS S3 / Cloudinary (for media files) |
| **State Management** | Redux Toolkit / Context API |
| **API Testing** | Postman / Thunder Client |
| **Version Control** | Git + GitHub |
| **Deployment** | Render / Vercel (Frontend), Railway / AWS (Backend) |

---

## 🧠 Architecture Overview

**Frontend (React.js)** → consumes REST APIs from  
**Backend (Node + Express)** → communicates with  
**Database (MongoDB)** for data persistence and  
**Storage (AWS/Cloudinary)** for media management.

### High-Level Modules:
- Authentication (JWT)
- User Management (Admin / Trainer / Student)
- Course Management
- Batch & Schedule Management
- Assessment & Quiz Engine
- Attendance Tracking
- Certificate Generation
- Notifications
